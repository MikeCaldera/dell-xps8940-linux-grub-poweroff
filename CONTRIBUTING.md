# Contributing

Reports from other Dell XPS 8940 owners and users of different boards are welcome, whether the workaround works or fails. Please distinguish first-hand tested behavior from hypotheses. The aim is to collect reliable reproduction steps without incorrectly declaring a universal Linux kernel 7.x bug.

For a new hardware report, use the GitHub Issue template. Do not post raw personal logs; redact unique identifiers, private file paths, IPs, serial numbers, credentials, and sensitive project data.

The optional one-command and desktop paths are examples, **not independently validated on the original machine**. Please report outcomes and GRUB filesystem layout if testing them. Never run GRUB `halt` in place of a normal running-OS shutdown.
